# Database Schema Overview

**Target Engine:** SQL Server 2022 (`mcr.microsoft.com/mssql/server:2022-latest`)  
**Database Name:** `CrisisPlatform`  
**Schema:** `dbo`  
**Migration Strategy:** Ordered, idempotent T-SQL scripts under `database/migrations/`

---

## Design Principles

1. **Surrogate Primary Keys:** Every table uses `UNIQUEIDENTIFIER` (`Guid`) primary keys generated by the application or `NEWSEQUENTIALID()` where clustered index locality is required.
2. **UTC Timestamps:** All temporal columns use `DATETIMEOFFSET(7)` stored in UTC.
3. **Optimistic Concurrency:** Mutable aggregate roots (`AidRequests`, `Shelters`, `Resources`, `RoleChangeRequests`, `OutboxMessages`) carry a `RowVersion ROWVERSION NOT NULL` concurrency token.
4. **Soft Delete:** User-facing operational tables (`Users`, `AidRequests`, `Shelters`, `Resources`, `Volunteers`, `Donations`) use a nullable `DeletedAt DATETIMEOFFSET(7)` column rather than hard deletes, preserving referential history.
5. **PII Protection:** National Identity Card (NIC) values are never stored in plaintext. `Users` stores `EncryptedNic` (AES-256-GCM ciphertext) and `NicHash` (keyed HMAC-SHA256 for uniqueness).
6. **Append-Only Auditing:** `AuditEntries` is protected by SQL triggers blocking `UPDATE`, `DELETE`, and `TRUNCATE`, and links rows via a SHA-256 hash chain (`PrevHash`, `EntryHash`).

## Table Inventory

### Identity & Access

| Table | Purpose | Key Columns |
|---|---|---|
| `Roles` | Reference table of platform roles (`Citizen`, `Volunteer`, `Staff`, `Coordinator`, `Admin`) | `Id`, `Name` (UQ), `Description` |
| `Users` | Registered citizens, volunteers, staff, coordinators, and admins | `Id`, `FullName`, `Email` (UQ), `NicHash` (UQ), `EncryptedNic`, `Role`, `IsLocked`, `FailedLoginAttempts`, `DeletedAt` |
| `RefreshTokens` | Rotating, revocable refresh tokens | `Id`, `UserId` (FK), `TokenHash` (UQ), `ExpiresAt`, `IsRevoked`, `ReplacedByTokenId` |
| `OtpChallenges` | Short-lived hashed OTP codes with cooldown tracking | `Id`, `UserId` (FK), `CodeHash`, `Purpose`, `ExpiresAt`, `ConsumedAt` |
| `StaffInvitations` | Single-use 24-hour staff onboarding invitations | `Id`, `Email`, `Role`, `TokenHash` (UQ), `InvitedBy` (FK), `ExpiresAt`, `AcceptedAt` |
| `RoleChangeRequests` | Two-person (four-eyes) role promotion workflow | `Id`, `TargetUserId` (FK), `NewRole`, `RequestedBy` (FK), `ApprovedBy` (FK), `State`, `RequestedAt`, `ExpiresAt`, `ApprovedAt` |

### Reference & Geography

| Table | Purpose | Key Columns |
|---|---|---|
| `Districts` | Reference table of the 25 administrative districts of Sri Lanka | `Id`, `Code` (UQ), `Name` (UQ), `Province`, `Latitude`, `Longitude` |
| `NeedCategories` | Reference table of aid request need types (`Food`, `Water`, `Medical`, `Shelter`, `Evacuation`, `Other`) | `Id`, `Code` (UQ), `DisplayName`, `IsActive` |

### Aid Requests & Human-in-the-Loop AI

| Table | Purpose | Key Columns |
|---|---|---|
| `AidRequests` | Citizen emergency aid requests | `Id`, `CitizenId` (FK), `NicHash`, `District`, `NeedType`, `Urgency` (1–5), `Description`, `ContactPhone`, `Latitude`, `Longitude`, `Status`, `IdempotencyKey` (UQ filtered), `AssignedVolunteerId` (FK), `RowVersion`, `CreatedAt`, `DeletedAt` |
| `RequestConversations` | Conversation threads attached to an aid request | `Id`, `RequestId` (FK), `CreatedAt`, `UpdatedAt` |
| `RequestMessages` | Messages exchanged within a request conversation | `Id`, `ConversationId` (FK), `RequestId` (FK), `SenderId` (FK), `Body`, `SentAt` |
| `AiRecommendations` | AI-generated triage/allocation suggestions awaiting human approval | `Id`, `RequestId` (FK), `SuggestedAction`, `Confidence`, `Status`, `DecidedBy` (FK), `ApprovedBy` (FK), `DecisionNote`, `CreatedAt` |

### Shelters, Resources, Volunteers & Donations

| Table | Purpose | Key Columns |
|---|---|---|
| `Shelters` | Emergency shelters with capacity tracking | `Id`, `Name`, `District`, `Latitude`, `Longitude`, `Capacity` (`>= 0`), `CurrentOccupancy` (`0 <= CurrentOccupancy <= Capacity`), `RowVersion`, `DeletedAt` |
| `Resources` | Relief inventory managed by coordinator/partner organisations | `Id`, `Name`, `Type`, `District`, `Quantity` (`>= 0`), `ManagedByOrg`, `RowVersion`, `DeletedAt` |
| `Volunteers` | Volunteer profiles and availability | `Id`, `UserId` (FK, UQ), `District`, `Skills`, `IsAvailable`, `DeletedAt` |
| `Donations` | Monetary and in-kind donation ledger | `Id`, `DonorId` (FK), `Amount` (`> 0`), `Currency`, `DonatedAt`, `DeletedAt` |

### Messaging & Tamper-Evident Audit

| Table | Purpose | Key Columns |
|---|---|---|
| `OutboxMessages` | Transactional outbox for reliable async notifications | `Id`, `IdempotencyKey` (UQ), `EventType`, `PayloadJson`, `Status`, `AttemptCount`, `NextAttemptAt`, `LastError`, `SentAt`, `RowVersion` |
| `AuditEntries` | Immutable, hash-chained security and operational audit log | `Id`, `Action`, `PerformedBy`, `TargetEntity`, `TargetId`, `DetailsJson`, `PrevHash`, `EntryHash`, `Timestamp` |
